# Reproducibility

Use Python 3.10–3.12, NumPy, SciPy, PyTorch, scikit-learn, and RDKit. The paper-facing path uses float32 geometry/chemistry storage and float64 spectral algebra (`fp64_stable`). Fit vocabulary statistics on training tokens only and persist tau. PDBbind/CASF structures and labels must be obtained from their providers under their terms; they are not shipped here.
