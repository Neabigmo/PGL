# Examples

`toy/` holds 60 synthetic complexes used by the README quickstart. Each sample is a
short idealised helix together with a small ligand placed next to its surface.
The complexes are generated by `make_toy.py`; the affinity labels in
`toy/labels.csv` are a fixed function of the computed contact tokens, so the toy
readout has something to fit. The dataset exercises the whole pipeline and has no
scientific meaning.

Regenerate after changing the operator or the feature layout:

```bash
python examples/make_toy.py
```

Regeneration is deterministic: the same code produces the same files and labels.
